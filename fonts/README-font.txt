Fulgido Mincho (fulgido-mincho.woff2)

This font is a Derived Program of IPA Mincho (IPAMincho Regular),
released by the Information-technology Promotion Agency, Japan (IPA)
under the IPA Font License Agreement v1.0 (see LICENSE-IPA-Font.txt).
This derived font is licensed under the same agreement.

Changes from the original: the font was subset to Latin characters and
basic punctuation, converted to WOFF2 for the web, and renamed as required
by Article 3.1(4) of the agreement. No glyph outlines were modified.
It was created with fontTools (pyftsubset); no other editing files exist.

How to replace it with the original IPA Mincho:
1. Download IPA Mincho (ipam.ttf) from the official IPA font distribution.
2. Put it in this folder.
3. In each HTML page, change
     src:url("fonts/fulgido-mincho.woff2") format("woff2")
   to
     src:url("fonts/ipam.ttf") format("truetype")
